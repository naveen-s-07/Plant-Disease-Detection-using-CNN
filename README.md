# 🌱 Plant Disease Detection using CNN

This project implements a **Convolutional Neural Network (CNN)** model to automatically detect and classify plant leaf diseases. Early detection helps farmers take preventive measures, ensuring better crop yield and sustainable agriculture.

---

## 📖 Overview
- Detects multiple plant diseases from leaf images.  
- Built using **CNN (Convolutional Neural Networks)**.  
- Supports **multi-class classification**.  
- Helps in real-time plant health monitoring.  

---

## 🔍 Features
- ✅ Image preprocessing (resize, normalize, augment)  
- ✅ Multi-class disease classification  
- ✅ High accuracy with deep learning  
- ✅ Visualization of training performance  
- ✅ Prediction function for new images  

---

## 🛠️ Tech Stack
- **Programming Language:** Python  
- **Frameworks/Libraries:** TensorFlow, Keras, OpenCV, NumPy, Pandas, Matplotlib, Seaborn  
- **Tools:** Jupyter Notebook / Google Colab  

---

## 🚀 Workflow
1. **Dataset Preparation** – Load and preprocess leaf images.  
2. **Preprocessing** – Resize, normalize, and augment images.  
3. **Model Building** – Define CNN architecture.  
4. **Training** – Train model with training dataset.  
5. **Evaluation** – Measure accuracy, precision, recall, and F1-score.  
6. **Prediction** – Use trained model to classify new images.
